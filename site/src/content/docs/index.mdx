## What gets missed

<CardGrid>
  <Card title="Package boundaries" icon="puzzle">
    Deep imports into another package's internals, unlisted dependencies, and no boundary enforcement.
  </Card>
  <Card title="Circular dependencies" icon="random">
    Package and file cycles, ranked by whether a binding is read during module evaluation.
  </Card>
  <Card title="Task caching" icon="rocket">
    Cache keys that miss env vars or outputs and replay stale green results, or inputs that rebuild too often.
  </Card>
  <Card title="CI test coverage" icon="warning">
    Shallow checkouts, missing base refs and undeclared workspace deps that make affected tests skip silently.
  </Card>
  <Card title="Test code in production" icon="error">
    Specs, fixtures and test libraries that end up in published tarballs or deployable builds.
  </Card>
</CardGrid>
